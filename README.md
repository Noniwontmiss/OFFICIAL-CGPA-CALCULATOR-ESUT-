# ESUT CGPA Calculator

A mobile-friendly cumulative CGPA calculator based on:

- A = 5
- B = 4
- C = 3
- D = 2
- E = 1
- F = 0
- Quality Point = Grade Point × Credit Unit
- CGPA = Total Quality Points ÷ Total Credit Units

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current features

- Multiple semesters from 100L to 500L
- Course code, title, credit unit and grade entry
- Automatic quality-point calculation
- Semester GP
- Cumulative CGPA across all entered semesters
- Degree classification
- Local browser saving
- Mobile-responsive interface
